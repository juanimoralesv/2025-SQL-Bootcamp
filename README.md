## Contenidos del Repositorio
Repositorio con los contenidos trabajados en el Bootcamp de SQL dictado por José Portilla de Pierian Data en Udemy. Pueden encontrarse los archivos .sql con las consultas practicadas en PostgreSQL durante las lecciones en cada sección. Cada archivo corresponde a una sección diferente, con excepción de la 10-02.

Adicionalmente, se presentan cuadernos de Jupyter, donde se ejecutan las consultas de SQL embebidas en código escrito en Python y usando bibliotecas como `pandas` y `sqlite3`. Fue necesario adaptar las consultas debido al paso de PostgreSQL a SQLite.

Por último, al inicio de cada cuaderno se observa la definición de funciones en Python, para simplificar la tarea del armado de los cuadernos. Dichas funciones van complejizándose con el avance de las secciones, logrando mejorar el ahorro de tiempo.

Los notebooks deberían ser fácilmente visualizables aquí en GitHub.


## Repository Contents
Repository with the contents worked on in the SQL Bootcamp taught by José Portilla from Pierian Data on Udemy. The .sql files containing the queries practiced in PostgreSQL during the lessons can be found in each section. Each file corresponds to a different section, except for 10-02.

Additionally, Jupyter notebooks are presented, where SQL queries are executed embedded in code written in Python, using libraries such as `pandas` and `sqlite3`. It was necessary to adapt the queries due to the transition from PostgreSQL to SQLite.

Finally, at the beginning of each notebook, the definition of functions in Python can be seen, to simplify the task of assembling the notebooks. These functions become more complex as the sections progress, improving time savings.

The notebooks should be easily viewable here on GitHub.
